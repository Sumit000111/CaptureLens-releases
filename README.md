# CaptureLens — Releases

This repo holds nothing but downloadable builds of **CaptureLens**.
Source code lives in a separate, private repository.

## Download

Grab `CaptureLens.exe` from the [Releases](../../releases) page — one
file, no installer, no separate .NET runtime required. Run it as
Administrator (right-click → Run as administrator); it'll prompt for
elevation either way.

CaptureLens lists apps that have been caught hiding a window from
screen capture, and resolves them either by hand or automatically as
they're detected, with a timestamped history of every capture.

## Requirements

- Windows 10 (2004+) or Windows 11, 64-bit.
- Administrator rights (only needed for the reset/capture action;
  listing works without elevation).
